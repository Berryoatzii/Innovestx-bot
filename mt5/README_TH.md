# 🤖 ScalpingRobotSafe — บอตเทรดทอง (XAUUSD) อัตโนมัติ สายปลอดภัย

บอต Expert Advisor (EA) สำหรับ MetaTrader 5 ที่เทรด **ทองคำ XAUUSD อย่างเดียว**
ออกแบบให้ **ปลอดภัยเป็นหลัก** สำหรับคนที่ไม่มีพื้นความรู้ด้าน IT

> ⚠️ **อ่านก่อน:** บอตนี้เป็นเครื่องมือช่วยเทรด **ไม่รับประกันกำไร** การเทรดมีความเสี่ยง
> **ต้องทดสอบบนบัญชีทดลอง (DEMO) ก่อนเสมอ** อย่างน้อย 2–4 สัปดาห์ ก่อนใช้เงินจริง

## 📥 วิธีติดตั้ง (ทำทีละขั้น)

### ขั้นที่ 1 — เปิดโปรแกรมแก้ไขโค้ด
1. เปิด **MetaTrader 5** บนคอม
2. กดปุ่ม **IDE** ด้านบน หรือกด **F4** เพื่อเปิด **MetaEditor**

### ขั้นที่ 2 — เอาไฟล์บอตเข้าไป
1. ใน MetaEditor ด้านซ้าย คลิกขวาที่โฟลเดอร์ **Experts** → **New File** → **Expert Advisor** (หรือลากไฟล์เข้าก็ได้)
2. เอาเนื้อหาไฟล์ **`ScalpingRobotSafe.mq5`** วางลงไป แล้ว **Save**
   - หรือคัดลอกไฟล์ `ScalpingRobotSafe.mq5` ไปวางในโฟลเดอร์
     `MQL5/Experts/` (เมนู **File → Open Data Folder** ใน MT5 จะเจอโฟลเดอร์นี้)

### ขั้นที่ 3 — คอมไพล์ (แปลงเป็นบอต)
1. กดปุ่ม **Compile** หรือกด **F7**
2. ถ้าขึ้น **0 errors** = สำเร็จ ✅

### ขั้นที่ 4 — เปิดกราฟทอง
1. กลับมาที่ MT5
2. เปิดกราฟ **XAUUSD** ตั้ง Timeframe เป็น **M5**

### ขั้นที่ 5 — เปิดใช้ Auto Trading
1. กดปุ่ม **Algo Trading** ด้านบนให้เป็น **สีเขียว** (สำคัญมาก ถ้าไม่เขียวบอตจะไม่เทรด)

### ขั้นที่ 6 — ลากบอตใส่กราฟ
1. ในหน้าต่าง **Navigator** ซ้ายมือ → **Expert Advisors** → ดับเบิลคลิก **ScalpingRobotSafe** (หรือลากใส่กราฟ)
2. แท็บ **Common**: ติ๊ก **Allow Algo Trading**
3. แท็บ **Inputs**: ปรับค่าได้ (ดูตารางด้านล่าง) — ถ้าไม่แน่ใจ **ใช้ค่าเริ่มต้นได้เลย**
4. กด **OK**

เสร็จแล้ว! ถ้ามุมขวาบนของกราฟมี **หน้ายิ้ม 🙂** และมีตารางสรุปขึ้นมุมซ้ายบน = บอตทำงานแล้ว ✅

## ⚙️ ค่าที่ควรรู้ (Inputs)

| ค่า | ความหมาย | แนะนำ |
|---|---|---|
| `InpMaxAccountDDPct` | เพดานขาดทุนเงินต้น → หยุดถาวร | **20** (ตามที่ต้องการ) |
| `InpRiskPerTradePct` | เสี่ยงกี่ % ต่อไม้ | 0.5 (ปลอดภัย) |
| `InpMaxDailyLossPct` | ขาดทุนต่อวันเท่านี้แล้วพัก | 5 |
| `InpMaxOpenPositions` | เปิดพร้อมกันกี่ไม้ | 1 |
| `InpTimeframe` | ไทม์เฟรม | M5 |
| `InpUseNewsFilter` | หลบข่าว | true |
| `InpUseSession` | จำกัดช่วงเวลา | true |

> 💡 **เงินต้น** ที่บอตใช้คำนวณ 20% คือ balance ตอนที่รันบอตครั้งแรก (เก็บอัตโนมัติ)
> ถ้าจะรีเซ็ตค่านี้ ให้ลบตัวแปร Global ชื่อ `SRS_START_...` และ `SRS_HALT_...`
> ที่เมนู **Tools → Global Variables (F3)**

## ⚠️ ข้อจำกัด / ความจริงที่ต้องเข้าใจ

- **ไม่มีบอตไหนรับประกันกำไร** คำโฆษณา "engineered for profits" เป็นการตลาด
- เพดาน 20% เป็นการ **ปิดออเดอร์และหยุด** แต่ในกรณีตลาดกระโดด (gap)/สภาพคล่องหาย
  อาจขาดทุนเกินเป้าเล็กน้อยได้ (slippage) — ไม่ใช่การรับประกัน 100%
- กลยุทธ์ในบอตเป็นแนว EMA cross + RSI + กรองเทรนด์ (ออกแบบใหม่ ไม่ใช่โค้ดของสินค้าต้นฉบับ)
  ควร backtest และจูนค่าให้เข้ากับโบรกเกอร์/สเปรดของคุณเอง
